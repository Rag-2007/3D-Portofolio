# 3D Developer Portfolio

A modern, fully responsive 3D portfolio showcasing my work as a Full-Stack Software Engineer. Built with React.js, Three.js, and Tailwind CSS, featuring interactive 3D graphics and smooth animations.

**🔗 Live Demo:** [https://3-d-portofolio-beige.vercel.app/]

## 🌟 Key Features

- **Interactive 3D Graphics**: Built using Three.js and React Three Fiber.
- **Beautiful Animations**: Smooth page transitions and element animations powered by Framer Motion.
- **Fully Responsive**: Optimized for seamless viewing on mobile, tablet, and desktop devices.
- **Modern UI/UX**: Designed with Tailwind CSS for a sleek, dark-themed aesthetic.

## 💻 Tech Stack

- **Frontend:** React.js, TypeScript, Tailwind CSS
- **3D Rendering:** Three.js, React Three Fiber, React Three Drei
- **Animations:** Framer Motion
- **Tooling:** Vite, ESLint, PostCSS
